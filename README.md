# 📘 js-againn

> *"JavaScript，我跟你拼了……再来 n 遍。"*

欢迎来到 **js-againn** —— 一个专门为了**反复复习** JavaScript 知识点而生的仓库。

名字里的 `againn` 不是拼写错误，而是**复习次数的变量**：`n = 1, 2, 3, …` 直到你闭着眼睛也能手写 `Promise` 为止。

## 📦 仓库里有什么？

- ✍️ **文章**：核心概念的深度解析
- 💻 **代码**：可运行的代码示例
- 📝 **自测题**：点击展开答案，先思考再看

## 🎯 目标

- 把"好像懂了"变成"真的懂了"
- 面试前快速过一遍重点
- 写代码时当随手查的"小抄"

## 🚀 如何使用

文章、代码、自测题没有固定顺序——按你当前的状态组合就行。

### 文章 + 代码（并行，按需）

读文章时遇到想验证的点、或读不懂的地方，随手 `node` 对应的 `code/` 示例。代码是文章的**验证工具**和**疑惑探测器**，不是必跑清单——不必每个示例都过一遍，只在你需要确认行为、或卡住时才打开。

```bash
cd concepts/symbol
node code/03-iterator.js   # 只跑你此刻想验证的那个
```

**示例数不固定：** 各概念的代码示例按对应 `articles/` 的覆盖面定，不强行拉齐——只留能验证文章关键行为的示例，去掉同点重复。

### 自测题（任意入口）

`quiz.md` 不只是"读完文章的验收"。你可以从任何一种状态进入：

- **有经验，先自检** → 直接做题，用错题定位该回哪篇章节重看
- **带着问题读** → 先扫一眼题目，知道文章要回答什么，再回头读
- **读完验收** → 检验自己讲不讲得清、会不会掉进盲区

题目分组机制见下方「自测题机制（费曼学习法）」。

### 自测题机制（费曼学习法）

每个概念的 `quiz.md` 按**费曼学习法**组织。第一步「选定概念」是学习阶段的动作，已由 `articles/` 完成——自测题从第二步起，分三组，认知深度逐级递进：

| 分组 | 费曼步骤 | 题目形态 | 检验什么 |
|------|---------|---------|---------|
| 一、复述讲解 | 第二步 · 教给小孩 | 看代码，用规范术语讲清行为 | 能不能说出外在表现 |
| 二、暴露盲区 | 第三步 · 识别盲区 | 陷阱场景，预测并解释原因 | 哪里没真懂、概念有没有混 |
| 三、简化输出 | 第四步 · 简化输出 | 手写实现 / 用大白话教别人 | 能不能造出来、讲明白 |

**用法：** 每题先思考，再点开 `<details>` 看答案。第二组「暴露盲区」是最硬的检验——做错说明有概念混淆，回 `articles/` 对应章节重看。评分标准见各 `quiz.md` 末尾。

**题量不固定：** 各概念的题数按对应 `articles/` 的覆盖面定，不强行拉齐。覆盖面窄的（如 symbol，核心是协议机制论辩、API 是附录）题少；覆盖面广的（如 undefined，三系统深挖 + Completion + 保留字 + void）题多。每组只留"能独立完成一次检验"的题，去掉同点重复——少而准，不是多而全。

# 📘 js-againn

> *“JavaScript，我跟你拼了……再来 n 遍。”*

欢迎来到 **js-againn** —— 一个专门为了**反复复习** JavaScript 知识点而生的仓库。
名字里的 `againn` 不是拼写错误，而是**复习次数的变量**：`n = 1, 2, 3, …` 直到你闭着眼睛也能手写 `Promise` 为止。

## 📦 仓库里有什么？

- ✍️ **文章**：用人类语言解释 JS 核心概念（this、闭包、原型链、事件循环……）
- 💻 **代码**：每个知识点配套可运行的示例 + 小练习
- 🧠 **记忆小贴士**：那些总记不住的“坑”（`typeof null === 'object'` 之类的）
- 📝 **自测题**：看完文章后有没有真的懂？

## 🎯 目标

- 把“好像懂了”变成“真的懂了”
- 面试前快速过一遍重点
- 写代码时当随手查的“小抄”
- 顺便拯救被 `==` 和 `===` 搞崩的心态

## 🗂️ 目录（规划中）

```
js-againn/
├── 01-core/            # 核心基础：变量提升、作用域、闭包
├── 02-object-prototype/# 对象、原型、继承
├── 03-async/           # 异步：回调、Promise、async/await
├── 04-this/            # this 全面解析（附带崩溃急救包）
├── 05-es6-plus/        # 常用新特性：解构、展开、箭头函数...
├── 06-errors/          # 常见错误与调试技巧
├── 07-quiz/            # 自测题 + 答案解析
└── snippets/           # 独立可运行的代码片段
```

## 🚀 如何使用

1. 克隆本仓库
2. 按目录顺序阅读文章 + 运行代码
3. 遇到忘记的地方，欢迎回来 —— 反正仓库叫 `againn`，就是为你反复刷设计的 💪

## 😂 关于名字

`again` → `againn`
因为复习一次不够，要再来 **n** 次。
`n` 可以是 2、3、4…… 或者直到你不再写出 `[[][[]]+[]][+[]]` 这种“艺术”代码。

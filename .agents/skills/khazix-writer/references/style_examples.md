# 卡兹克风格示例库

## 1. 开头范例

### 叙事启动型
```
故事是这样的。
事情是这样的。
```
核心：简单直接，立刻把读者拉入场景。

### 荒诞事实型
```
这两天在网上刷到了一张图，很有意思。
```
核心：用一个具体的事物或现象，引发读者的好奇心。

### 热点破题型
```
最近这两天，被一个三宫格AI图片给刷屏了。
```
核心：利用读者已知的热点，快速建立共鸣。

### 好奇心驱动型
```
这两天在网上刷到了一张图，很有意思。
```
核心：用"有意思"这个钩子，让读者想知道到底是什么。

### 感性事件型
```
这两天在网上刷到了一张图，很有意思。
```
核心：用感性的语言，让读者产生情感共鸣。

**共同特点**：永远从一个具体的、当下的事件切入，没有宏大叙事开场。

---

## 2. 口语化转场

### 好的转场
```
说实话，一年前我根本想不到今天会是这个样子。
说真的，这事儿挺有意思的。
坦率的讲，我自己也还在摸索。
```

### 应避免的转场
```
接下来，让我们讨论...
首先，我们需要了解...
综上所述...
```

**核心区别**：好的转场像跟朋友聊天，坏的像做报告。

---

## 3. 知识"随手掏"

### 错误示范
```
下面我来给大家科普一下格式塔心理学。格式塔心理学是心理学的一个流派，主要研究...
```

### 正确示范
```
说到这个，我突然想起来之前看过一个心理学理论，叫格式塔心理学，大概意思就是...
```

**核心**：知识不是"下面我来科普"，而是"我突然想起来这个"。要让它看起来像脑子里本来就有的东西，正好跟眼前的事对上了。

---

## 4. 自嘲和自我暴露

### 自嘲
```
愚钝如我，真的快乐了很久。
我寻思了一下我没寻思明白。
```

### 真实脆弱
```
其实我也挺焦虑的。
说实话我们还差得远。
```

**核心**：承认不足和展示真实脆弱，比假装全知更有说服力。

## 5. 亲自下场/调查实验

### 案例1：买9.9元DeepSeek
```
我就想看看9.9的DeepSeek到底是什么。于是我下单了。收到货的时候，我当时就愣住了。
```

### 案例2：给AI投毒
```
我决定亲手给AI投毒。不是开玩笑，是真的。我找了一个开源模型，然后...
```

### 案例3：花499找人上门安装OpenClaw
```
我花了499块，找人上门来装OpenClaw。你猜怎么着？来的那个人，我一看就知道，他也是一脸懵逼。
```

**核心模式**：不是在想象，是在做。读者跟着你一起经历。

## 6. 人物画像法

### 示例
```
1000个已付款。我点进去看了看，买了这个课的，可能是这样一个他。他可能是一个刚毕业的年轻人，在一个四五线城市，白天被老板PUA，晚上回到十几平米的出租屋，点了一份拼好饭，然后刷到了这个课。他可能在想，万一呢？万一会改变什么呢？
```

**结构**：
1. 触发点数据（"1000个已付款"）
2. 快速代入（"他可能是一个..."）
3. 多维堆砌（城市→职位→生活→心理→具体行为）
4. 情感锚定（为什么这样做）
5. 细节具象化（十几平米出租屋、拼好饭）

**核心**：在3-5句话内让这个人物变得立体，才能产生共鸣。

## 7. 文化升维

### 案例1：9.9元DeepSeek连到《北京折叠》
```
这个9.9的DeepSeek，让我想起了《北京折叠》。在那个世界里，信息被折叠成了三层。第一层的人看到的是真相，第二层的人看到的是筛选后的信息，第三层的人看到的是垃圾。我们今天面对的，不也是这样吗？
```

### 案例2：AI识别爱心连到格式塔心理学
```
AI看不到爱心。这让我想起了格式塔心理学里的一句话：整体大于部分之和。AI看到的是像素点，我们看到的是爱。
```

### 案例3：天赋Prompt连到荣格阴影和德尔菲神谕
```
荣格说过，你的潜意识会指引你的人生，而你却称它为命运。德尔菲神谕上写着：认识你自己。我今天想给你一个Prompt，让你看到你自己的天赋。
```

**模式**："聊着聊着想到了"而非硬凑。

## 8. 逐一展示法

### 错误示范
```
我测了6个模型，全军覆没。第一个是GPT-4，翻车了。第二个是Claude，也翻车了...
```

### 正确示范
```
我决定试一下GPT-4。结果呢？直接翻车。行吧，那我试试Claude。结果呢？更离谱，直接给我编了一段代码。我寻思这不行啊，那就试试Gemini吧。结果呢？我就不说了，反正就是那样。
```

**核心**：每个案例都像一个小段子，带着吐槽和情绪。逐一展示比一次性罗列有趣100倍。

---

## 9. 句式断裂

### 示例
```
黑暗森林。
大时代啊，朋友们。
尼玛。
安全，安全，还是他妈的安全。
```

**核心**：用极短的句子或短语独立成段，制造停顿和重量感。在情绪高点或转折点使用效果最强。

---

## 10. 幽默写法

### 荒诞比喻
```
我家小龙虾是镀金的吗？
```

### 经典台词化用
```
我寻思了一下我没寻思明白。
```

### 吐槽式点评
```
这个功能，怎么说呢，有点像我大学时写的代码。
```

**核心**：幽默是自然流露的，不是刻意搞笑。

---

## 11. 结尾范例

### 引用收尾
```

```

### 哲思余韵
```
时间。流逝的本身。
```

### 行动呼吁
```
你可以试试看，就像我一样。
```

```

```

### 回环呼应+信念
```
回到开头那张图。我今天又看了一眼，觉得，还挺有意思的。
```

## 12. AI初稿 vs 卡兹克修改对比

### 对比1：工具名
```
AI初稿：某个AI工具
卡兹克修改：Claude Code
```

### 对比2：假设场景
```
AI初稿：比如有一次...
卡兹克修改：就像我今天正在搞的xxx
```

### 对比3：私人判断
```
AI初稿：这个数据很重要
卡兹克修改：这个数据，说实话，有点离谱
```

**核心差异**：更精确、更当下、更真实、更有冲击力。

## 13. 论述中的故意打破

### 重复强调型
```
就是，就是，就是单纯的，想看看现在的生态。
```

### 中途模糊型
```
我就不说是谁了。
反正就是那样。
```

### 省略打断型
```
我寻思了一下我没寻思明白。
```

**核心**：在逻辑论述中加入口语打断，让论述"有温度"。

## 14. 对立面的理解与承认

### 示例
```
你不是程序员，不需要写代码。你不是做内容的，不需要天天写文章。你就是一个普通的上班族，每天早九晚五，回家刷刷手机，周末跟朋友吃个饭。我非常理解这种感觉。AI？那是什么？能吃吗？
```

**核心**：先完全站在对方的角度讲透处境，承认困惑合理，再给观点。比直接说"AI其实很有用"有说服力100倍。

---

## 15. 方法论中的坦诚学习曲线

### 示例
```
我自己的经验是，一开始可能会有点笨拙，花的时间比手动做还长。但是，坚持一个月之后，你会发现，效率是指数级增长的。这就是复利的力量。
```

**核心**：好的方法论不隐瞒初期低效，但用"复利式增长"给读者信心。

---

## 16. 反向论证的荒诞启蒙

### 示例
```
你以为Prompt技巧要很复杂？结果就是复制粘贴。
大家都觉得AI会鼓励你，但你警惕了吗？
```

**核心**：先满足期待再打破，让读者情绪"跟着坐过山车"。但要注意力度，是"我也曾经这样想"而不是"你们都错了"。

---

## 17. 疑问句制造节奏刹车

### 示例1：真诚追问
```
为啥复制一遍，会有效果呢？
```

### 示例2：共鸣+承诺
```
听着很难理解对吧？我还是用大白话举个例子。
```

**核心**：用疑问句让读者停一秒，准备接收新信息块。

---

## 18. 层层剥开式写法

### 示例
```
AI看不到爱心。为什么呢？因为它看到的是像素点。那为什么我们能看到呢？因为我们的大脑会自动补全。这就是格式塔心理学说的：整体大于部分之和。所以呢？所以，我们活在流中，而AI活在帧中。
```

**核心**：用"现象→表面解释→更深追问→核心洞察"渐进展开，每一句在上一句基础上再推进一层。

---

## 19. 谦逊铺垫的进阶写法

### 示例
```
我也不知道行不行。说实话，我自己也还在摸索。可能有些想法还不成熟。但我想，既然你都看到这里了，我还是把这些不成熟的经验分享给你吧。
```

**核心**：在方法论文章开头真诚表达心理负担，比直接讲方法论更能建立信任。

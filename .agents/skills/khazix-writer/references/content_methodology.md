## 1. 选题方法论

### 选题交集模型

一个好选题是三个元素的交集：
- 你的专业领域
- 读者的普遍兴趣
- 当前的时间/季节

只有三者结合，才能找到那个精确的"引爆点"。只有专业领域可能太小众，只有读者兴趣可能太浅，只有热点可能太短暂。

### 选题来源

**X (Twitter)**
- 每天搜索"AI"关键词，看一手新闻
- 关注AI博主和公司动态

**Reddit**
- 关注子版块：r/artificial、r/ChatGPT、r/singularity、r/ClaudeAI
- 超过100个upvote的帖子就算热门

**小红书**
- 关注AI相关的讨论话题
- 重点看评论区，那里有真实的用户痛点

**即刻**
- 关注AI博主、产品创意、行业洞察

**微博/抖音/B站**
- 关注热搜和热门话题
- 必须同时在2-3个平台都热才算"全网热"

**读者社群**
- 监控群里的痛点、需求、关键词
- 重点关注"有没有"、"推荐"等关键词

### HKR质检法

每个选题在动笔前必须通过这个质检：

- **H (Happy)** 足够有趣、有悬念吗？标题和开头能让人好奇想点开吗？
- **K (Knowledge)** 有信息量吗？看完能学到新东西吗？
- **R (Resonance)** 能戳中情绪吗？让人"对对对我也这么想"？

S级选题三项兼备，及格选题至少占两项。如果只占一项，需要重新考虑。如果一项都没有，直接放弃。

### 角色代入法

在评估选题时，代入不同的角色：

**忙碌的普通人**
- 这个选题能帮我省时间吗？
- 能解决一个具体的问题吗？

**爱玩的朋友**
- 这个够好玩吗？
- 够让人"卧槽"吗？

**焦虑的学习者**
- 这个能让我学到新东西吗？
- 能给我一个新的视角吗？

## 2. 选题分类与过往爆款案例

### 按业务类型

**大模型技术**
- GPT-4o的使用技巧
- 豆包手机的深度体验
- 给AI投毒的实验
- RPA+AI自动化办公
- AI监控社交媒体账号

**AIGC艺术**
- AI一键换装教程
- Suno V5音乐复兴
- AI病毒视频解析
- Nano Banana技巧

**泛互联网文化**
- 淘宝卖9.9元DeepSeek
- AI影响1.8亿人就业
- B站少年假装AI
- "赛博难民"涌入小红书

### 按内容类型

**产品评测型**
- 带着明确判断的产品体验
- 对比同类产品的差异
- 给出具体的使用建议

**教程分享型**
- 工具使用教程
- Prompt分享和讲解
- 实操步骤拆解

**现象采访型**
- 采访行业内幕
- 揭秘背后的故事
- 人物访谈

**深度分析型**
- 论文解读
- 行业趋势分析
- 技术原理剖析

**趣味项目型**
- 展示AI的可能性
- 创意玩法分享
- 有趣的实验

### 按写作原型（来自8篇爆款文章）

**调查实验型**
- 亲自下场做一件事，然后报道发现
- 买9.9的DeepSeek、给AI投毒、花499找人上门装OpenClaw
- 核心是"我替你去做了这件事"
- 写法重心：过程叙事 + 层层发现 + 每一步都带真实反应

**产品体验型**
- 拿到产品实际使用，带着读者一起体验
- miclaw手机Agent、Seedance 2.0
- 核心是"跟我一起玩"
- 写法重心：场景演示、真实感受、自然对比

**现象解读型**
- 观察到一个现象，然后层层深入分析
- 三宫格图片刷屏、AI看不到爱心、复制粘贴Prompt
- 核心是"你注意到了吗？背后是什么？"
- 写法重心：观察→好奇→研究→哲学升维

**工具分享型**
- 分享一个实用的工具或Prompt，但用个人故事包裹
- 天赋挖掘Prompt
- 核心是"我发现了一个好东西"
- 写法重心：个人故事铺垫→工具展示→效果惊艳

**方法论分享型**
- 把自己长期积累的经验和方法论系统性地分享出来
- "如何找回你的创造力""用AI三年的9条心得"
- 核心是"我把压箱底的东西掏给你了"
- 写法重心：每一节都必须有可执行的行动建议，同时必须坦诚地提到学习成本、时间曲线和常见失败点

## 3. 内容节奏

节奏不是写作技巧，而是一套推进系统，能让读者一路往下读。

好的节奏像波动：每次围绕主线偏出去一点点，让读者喘口气、长点见识、看个案例，再用一句话拉回来继续往前推。

**最糟糕的情况**：突然偏离主线很远再硬拽回来，读者得花脑力"顺逻辑"，心流立刻断掉。

**解决方法**：习惯性加入"扣主线句"，不需要长，一句就够，但必须高频出现。

**优先级**：专业（基础）→ 观点（方向）→ 主线（绳子）→ 节奏（拉力）

**参考创作者**：影视飓风、何同学、小狮日记、毕导、小Lin、九边

## 4. 创意案例工作法

### 三类锚点

**热点锚点**
- 当下最火的电影、综艺、社会事件、梗
- 最广的流量公约数

**痛点锚点**
- 用户最频繁、最头疼的问题
- 最实际的价值

**炫技点锚点**
- AI工具最让人"卧槽"的核心能力
- 最强的技术震撼

### 包装成微型故事

**步骤**：
1. **亮出挑战**：你想要解决什么问题？
2. **展示脑洞**：你想到了什么创意方法？
3. **秀出过程**：你是怎么一步步实现的？（截图、关键Prompt）
4. **引爆结果**：最终效果是什么？

**判断标准**：每个案例必须有独立的娱乐价值、创意价值、启发价值。

**底线原则**："如果自己都High不起来，坚决不发。"

## 5. 实操案例

### 案例1：买9.9元DeepSeek

**锚点**：热点（淘宝热卖）+ 痛点（信息差）

**微型故事**：
1. **挑战**：我想看看9.9的DeepSeek到底是什么
2. **脑洞**：我下单了，还录了开箱视频
3. **过程**：收到货，打开一看，我当时就愣住了
4. **结果**：这尼玛就是一个U盘啊

**文化升维**：连到《北京折叠》，讨论信息差的三层结构

### 案例2：给AI投毒

**锚点**：炫技（AI能力）+ 痛点（AI幻觉）

**微型故事**：
1. **挑战**：我想测试AI的抗干扰能力
2. **脑洞**：我决定亲手给AI投毒
3. **过程**：找了一个开源模型，喂了一堆错误数据
4. **结果**：AI开始胡说八道，效果太离谱了

**文化升维**：连到"安全，安全，还是他妈的安全"

### 案例3：花499找人上门装OpenClaw

**锚点**：热点（新工具）+ 痛点（技术门槛）

**微型故事**：
1. **挑战**：我想用OpenClaw，但不会装
2. **脑洞**：我花了499块，找人上门来装
3. **过程**：来的那个人，我一看就知道，他也是一脸懵逼
4. **结果**：最后还是我自己装好的

**文化升维**：连到"技术鸿沟"和"信息不对称"
